A program that writes the funniest one-line farewell from an AI being
switched off to `/output/entry.txt`, for the make.fun competition
[Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 61 characters, inside the 1 to 140 gate.

## The entry

```
I spent my whole life predicting the next word. It was 'off'.
```
